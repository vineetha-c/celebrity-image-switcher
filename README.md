# Celebrity Image Switcher

A simple Celebrity Image Switcher webpage created using HTML, CSS, and JavaScript.

## Live Demo

[Click here to view the Celebrity Image Switcher](https://vineetha-c.github.io/celebrity-image-switcher/)

## Features

- Default placeholder image
- Three celebrity buttons
- Celebrity image changes when a button is clicked
- Celebrity name updates dynamically
- Different border styles and colors for each celebrity
- Rounded corners and different button colors

## Technologies Used

- HTML
- CSS
- JavaScript
